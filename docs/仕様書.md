# カレー作りゲーム プロジェクト仕様書

## 1. ゲーム概要

本プロジェクトは、プレイヤーが材料のカットからスパイスの投入までを行い、オリジナルのカレーを完成させる3Dゲームです。キーボード操作や外部コントローラーとの連携により、直感的な調理体験を提供します。完成したカレーは、投入したスパイスの組み合わせによって色や評価が変化します。

## 2. ゲームフロー

ゲームは大きく分けて以下の3つのシーンで構成されます。

1.  **スタート画面 (`control.tscn`)**
	* ゲームのタイトルが表示され、プレイヤーの開始入力を待ちます。
	* 「Enter」キーまたは画面上のボタンを押すことで、メインのゲームシーンへ遷移します。

2.  **ゲーム本編 (`node_3d.tscn`)**
	* **フェーズ1: 材料カット**
		* ゲームが始まると、ジャガイモとニンジンが目の前に出現します。
		* プレイヤーは「C」キーを規定回数（10回）連打することで、材料を一つずつカットします。
		* すべての材料をカットし終えると、次の「スパイス投入フェーズ」へ移行します。
	* **フェーズ2: スパイス投入（シューティング）**
		* 30秒の制限時間がスタートします。
		* プレイヤーは4種類のスパイス（弾）を切り替えながら、鍋に向かって発射します。
		* スパイスの発射は「Shoot」アクション、または連携する外部コントローラーを振ることで行います。
		* 制限時間がなくなると、自動的に調理フェーズへ進みます。
	* **フェーズ3: 調理と完成**
		* 鍋のフタが閉まり、鍋が激しく揺れる調理アニメーションが再生されます。
		* 投入されたスパイスの比率に基づいて、完成するカレーの色がリアルタイムに計算されます。
		* フタが開き、湯気（爆発エフェクト）と共に色鮮やかなカレーが姿を現します。
		* 完成したカレーの評価が内部で決定され、リザルト画面へ遷移します。

3.  **リザルト画面 (`result.tscn`)**
	* 完成したカレーの評価コメントが表示されます。
	* 「Enter」キーを押すことで、スタート画面に戻り、再度プレイすることができます。

## 3. 主要機能

* **インタラクティブな調理:** キー連打による材料カットや、狙いを定めてスパイスを撃ち込むシューティング要素。
* **動的なカレー生成:** 投入したスパイス（赤・青・緑・黄）の量に応じて、カレーの見た目（色）が変化します。
* **多彩な評価システム:** 完成したカレーのレシピに応じて、ユニークな評価コメントが生成されます。
* **外部コントローラー連携:** `PicoWController` と連携し、コントローラーを振ることでスパイスを投入できます。
* **アニメーションとVFX:** Tweenを利用した鍋の動きや、外部アセットを活用した爆発的な湯気のエフェクトで、調理のダイナミズムを演出します。

# コードファイルごとの説明書

## hassya.gd

これはゲームのメインロジックを担う最も重要なスクリプトです。ゲームの進行管理、プレイヤーの入力処理、オブジェクトの生成、アニメーションの制御など、ゲームプレイに関わるほぼ全ての処理を記述しています。

### 役割

`node_3d.tscn` シーンのルートノード（またはそれに準ずるノード）にアタッチされ、ゲーム全体の流れを制御します。

### 主要な変数

* `@export` 変数群: Godotエディタ上で設定するための変数です。
	* `explosion_scene`: 完成時に表示する爆発/湯気エフェクトのシーン。
	* `bullet_scene`各種: 発射する4種類のスパイス（弾）のシーン。
	* `potato_scene`, `carrot_scene`, `chunk_scene`: 材料とそのカケラのシーン。
	* `*_label`: UIに表示する各種テキストラベルのノード。
	* `naan_scene`: 調理中に登場するナンのシーン。
	* `lid_node`, `pot_body_node`など: アニメーションさせる鍋のフタや本体のノード。
* `is_cutting_phase`: ゲームが「材料カットフェーズ」か「スパイス投入フェーズ」かを判定するフラグ (`true`ならカットフェーズ)。
* `is_cooking`: 調理アニメーション中の操作を無効化するためのフラグ。
* `bullet_counts`: 投入された各スパイスの数を記録する辞書。
* `cut_press_count`: 材料をカットするためのキー連打回数をカウントします。

### 主要な関数

* `_ready()`: ゲーム開始時に一度だけ呼ばれます。変数の初期化、UIの初期表示設定、外部コントローラーとの接続設定などを行います。
* `_input(event)`: キーボード入力を検知します。
	* `is_cutting_phase` が `true` の時: `cut_material` アクション（Cキー）で材料のカット処理を呼び出します。
	* `is_cutting_phase` が `false` の時: `kirikae` アクションで弾を切り替え、`shoot` アクションで `shoot_bullet()` を呼び出します。
* `spawn_materials()`: ゲーム開始時にジャガイモとニンジンを生成・配置します。
* `shoot_bullet()`: 現在選択されている種類のスパイス（弾）をインスタンス化し、前方に発射します。
* `carryscene()`: 調理を開始する関数。タイマーを停止し、UIを非表示にし、鍋のフタを閉める → 鍋を振る → カレーの色を計算 → カレーを表示 → フタを開ける → 評価を決定、という一連の流れを実行し、最後にリザルトシーンへ遷移させます。
* `close_lid()`, `open_lid()`, `shake_pot()`: Tweenを使い、鍋のフタの開閉や鍋本体が揺れるアニメーションを滑らかに再生します。
* `evaluate_curry()`: `bullet_counts` の値に基づき、完成したカレーの評価テキストを返します。
* `_on_controller_shaken(amount)`: 外部コントローラー (PicoWController) から `seasoning_added` シグナルが送られてきた際に実行され、`shoot_bullet()` を呼び出します。
* `_on_timer_timeout()`: スパイス投入フェーズの制限時間（30秒）が終了したときに呼び出され、調理を開始する `carryscene()` を実行します。
* `_process(delta)`: 毎フレーム実行されます。主にスパイス投入フェーズの残り時間をUIラベルに表示を更新するために使用されます。

## control.gd

スタート画面を制御するシンプルなスクリプトです。

### 役割

`control.tscn` にアタッチされ、ゲームの開始を管理します。

### 機能

* `_on_button_pressed()`: UIボタンが押されたときに、ゲーム本編のシーン (`node_3d.tscn`) に切り替えます。
* `_input(event)`: Enterキーが押されたことを検知し、同様にゲーム本編のシーンに切り替えます。

## result.gd

リザルト画面を制御するスクリプトです。

### 役割

`result.tscn` にアタッチされ、ゲーム結果の表示と、タイトルへの復帰を管理します。

### 機能

* `@onready var label_node`: 結果を表示するための `Label` ノードを保持します。
* `_ready()`: シーンが読み込まれたときに実行されます。シングルトン（AutoLoad）の `ScoreManager` からカレーの評価テキスト (`curry_evaluation_text`) を取得し、`label_node` に表示します。
* `_unhandled_input(event)`: `ui_accept` アクション（EnterキーやSpaceキー）が押されたことを検知し、スタート画面 (`control.tscn`) にシーンを切り替えます。

## futa.gd

### 役割

このスクリプトは中身が空 (`extends StaticBody3D` のみ) です。これは、`futa` (フタ) のノードに `StaticBody3D` としての物理的な性質（当たり判定など）を持たせるためにアタッチされているものと推測されます。実際の動きの制御は `hassya.gd` 内の `Tween` によって行われているため、このスクリプト自体に処理の記述は不要です。
